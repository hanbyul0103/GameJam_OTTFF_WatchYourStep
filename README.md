## 기획 의도 📝
작은 세계를 현재 우리를 기준으로 하여 우리보다 작은 인간들이 사는 세계로 정의 하였습니다. 
우리가 정의한 작은 세계와 누구나 접근하기 쉬운 장르의 게임인 하이퍼 캐주얼을 어떻게 조합할까 모두 고민하다가
작은 인간도 존중 받아야 한다는 의견으로 작은 인간들을 피해 밟지 않는다는 것을 목표 삼아 기획하였습니다. 

<br>

## 시나리오 💬
<div align="center">작은 인간들만 사는 도시에 잘못 들어서 버린 주인공! <br>
주인공은 거인도 아닌데 강제로 거인이 되어버렸다. <br>
과연 작은 인간들을 밟지 않고 이 도시를 탈출할 수 있을까?</div>  

<br>

## 진행 방식 및 규칙 🧩
1. 마우스를 누르거나 마우스를 떼는 것을 알맞게 조종해 플레이어를 움직여 이동시킵니다.
   - 마우스를 누른 상태: 발이 바닥에 닿아있습니다.
   - 마우스를 뗀 상태: 발이 궁중에 떠있습니다.
   - 발은 오른발부터 왼발, 오른발 번갈아 바뀝니다.
   - 만약 플레이어를 이동하지 않고 계속 발이 궁중 상태에 있다면, 궁중에 떠있느 발은 서서히 땅에 닿습니다.
   - 기록은 걸음 수로 기록됩니다.
  
2. 작은 인간들을 밟지 않고 피해야 합니다.
   - 작은 인간들은 스폰되는 위치에 가만히 있지 않고 왔다 갔다 움직여서 플레이어를 방해하기 때문에 주의해야 합니다.
   - 만약 작은 인간들을 밟을 시, 작은 인간들을 비명을 지르며 죽기에 게임은 오버가 됩니다.

3. 시간 제한 타이머가 있기 때문에 앞으로 움직여야 합니다.
   - 움직이지 않을 시 시간 제한으로 인해 시간이 흐르므로 게임은 오버가 됩니다.
  
<br>
